"Used to", "Be used to" & "Get used to" in Bella Swan's immortal journey

Describe change with get used to + -ing / noun.

1

USED TO + infinitive

Function & Meaning

Past habits, repeated actions or past states that are no longer true today.

Note: there is no present form ("I use to…"). For present habits use the Present Simple.
Structure

[+] Subject + used to + base verb

[-] Subject + didn't use to + base verb

[?] Did + subject + use to + base verb?

⚠ After did / didn't the verb goes back to use to (no -d).

Examples

  • Bella used to live in sunny Arizona with her mother.
  • Edward didn't use to trust humans until he met Bella.
  • Did Bella use to like the rain? — No, she hated it.

2

BE USED TO + noun / verb-ing

Meaning: familiarity / comfort

To be accustomed to something: it is no longer strange, difficult or surprising.

Structure

Subject + BE (am / is / are / was / were) + used to + verb-ING / noun

He is used to cold blood. / She isn't used to running so fast.

Are you used to the dark?

Crucial difference:

In used to + infinitive "to" is part of the infinitive. Here "to" is a preposition, so the verb must end in -ING.

3

GET USED TO + noun / verb-ing

Process of change

The process of becoming accustomed to something new or difficult.

"Get" changes with the tense

• Present: She is getting used to the sunlight.

• Future: You will get used to it.

• Past: He couldn't get used to the noise.

• Perfect: I've got used to the rain.

Bella had to get used to moving at supernatural speed after her transformation.

Find & Fix the Mistakes

❌ Edward is used to live in the forest.

Key: Edward is used to living in the forest. (or: Edward used to live in the forest.)

❌ Bella didn't used to know about vampires.

Key: Bella didn't use to know about vampires.

❌ She is getting used to drink blood from animals.

Key: She is getting used to drinking blood from animals.
